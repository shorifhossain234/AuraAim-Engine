# AuraAim Engine - Professional Carrom Trajectory Predictor

AuraAim Engine is a high-precision real-time 2D vector physics and computer vision simulation framework designed for Android board games like Carrom Pool.

## Architecture Highlights
- **MediaProjection Engine:** High-speed 60FPS Android screen frame capture.
- **OpenCV Native C++ Module:** Circle detection & HSV color thresholding for puck coordinates.
- **Reflection Physics Engine:** Real-time multi-bounce cushion bounce vector calculation (`r = d - 2(d.n)n`).
- **Floating Overlay Canvas:** Android System Alert Window translucent UI rendering.
